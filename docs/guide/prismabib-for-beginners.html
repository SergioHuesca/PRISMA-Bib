Part 1: Install

First, install the app with one line. This command downloads the app and makes it available in your terminal.

uv tool install "prismabib[gui] @ git+https://github.com/SergioHuesca/PRISMA-Bib"

Then start the app with the command below. It opens the app in your browser. When you are done, press Stop the app.

prismabib gui

Parte 1: Instalación

Primero, instala la aplicación con una sola línea. Este comando descarga la aplicación y la deja disponible en tu terminal.

uv tool install "prismabib[gui] @ git+https://github.com/SergioHuesca/PRISMA-Bib"

Después, inicia la aplicación con el comando siguiente. Abre la aplicación en tu navegador. Cuando termines, pulsa Stop the app.

prismabib gui
