# Beginner Guide

The beginner guide takes you from an empty computer to a first set of results, in plain English
and Spanish, using the app that `prismabib gui` starts. It is one file that opens without a
network connection.

[Open the beginner guide](guide/prismabib-for-beginners.html) (`guide/prismabib-for-beginners.html`).

For the same steps on the command line, see [Getting Started](getting-started.md).
