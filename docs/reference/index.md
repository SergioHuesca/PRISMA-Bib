# API Reference

Generated by mkdocstrings from the source docstrings. §3.5's Definition of Done requires
every public function to appear here, so each module is rendered explicitly rather than
via a single `::: prismabib`.

A bare `::: prismabib` renders only what the package's `__all__` exports — currently just
`__version__` — so it produced a page with no API on it at all while `mkdocs build --strict`
still exited 0. CI cannot catch that, which is why the modules are listed one by one below:
a module added in a later stage without a section here is a visible omission.
